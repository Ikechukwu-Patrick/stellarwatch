# PulseForge

> Monitor your APIs. Detect failures. Stay informed.

![Python](https://img.shields.io/badge/Python-3.11%2B-blue)
![FastAPI](https://img.shields.io/badge/FastAPI-Modern-green)
![License](https://img.shields.io/badge/License-MIT-yellow)

PulseForge is an open-source API health monitoring platform that helps developers monitor the availability, health, and performance of their APIs through automated health checks and insightful metrics.

## Why PulseForge?

Developers often rely on expensive third-party monitoring services or manually check their APIs.

PulseForge provides a free and open-source alternative that can be self-hosted and extended by the community.

## Features

- API endpoint monitoring
- Automated health checks
- Response time tracking
- Uptime monitoring
- Historical health records
- REST API built with FastAPI

## Technology Stack

- Python
- FastAPI
- SQLAlchemy
- SQLite (MVP)
- Pytest
- GitHub Actions
